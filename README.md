# Expense Tracker

An Android app, written in Kotlin, for logging income and expenses, organizing them by category, and keeping an eye on your monthly budget.

## Features

- Add income and expense transactions with a note and date
- Organize transactions into default and custom categories
- Calendar view of your spending
- Reports with a pie chart breakdown by category
- Reminders via notifications
- Built-in calculator
- Data stored locally on your device with SQLite

## Tech

- Kotlin
- Android SDK (Activities, XML layouts, `SQLiteOpenHelper`, `SharedPreferences`)
- Custom `PieChartView` drawn with the Canvas API

## Build and run

1. Clone the repo.
2. Open it in Android Studio.
3. Run on an emulator or a connected device.
